# Resultados esperados da extracao

Cada `<nome>.json` e a foto do que as heuristicas devolvem para o PDF de mesmo
nome em `casos/`. Servem de teste de regressao: calibrar contra um artigo novo
nao pode quebrar os que ja funcionavam.

Estes JSON **entram no git**. Os PDFs, nao — sao obras de terceiros. Cada pessoa
mantem a propria pasta `casos/`.

Ver `docs/EXTRACAO.md` para o ciclo de trabalho.
